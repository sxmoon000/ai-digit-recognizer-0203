# ✍️ 手写数字识别

> MLP 神经网络识别 MNIST 手写数字 0-9

## 🧠 知识点
- **MLP (多层感知机)**: 最基础的神经网络，全连接层堆叠
- **StandardScaler**: 标准化特征到均值0方差1，加速训练
- **MNIST**: 机器学习界的 Hello World，28×28 灰度图
- **过拟合 vs 欠拟合**: hidden_layer_sizes 调参
